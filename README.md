# Estúdio de Bolso

Gravação em faixas no celular: guitarra pela USB (Cuvave), vídeo junto, edição, efeitos e tom.
Os projetos ficam só no celular (IndexedDB). Sem login e sem servidor.

- Publicar: mudar `VERSION` em `sw.js` e `VERSAO` em `src/main.js`, enviar para `main`.
- Testes de lógica: `node tests/dsp.test.mjs && node tests/recmap.test.mjs`.
